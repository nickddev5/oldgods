# 09 UI and controls

**Status:** PLACEHOLDER layout and wording; working and tested.

## Screens

| Screen | Where | What it does |
|---|---|---|
| Main menu | Menu scene | Begin, Shrine of Embers, Quests, Lore, Settings, Leave. First launch shows the premise. |
| Character select | Begin | Seven gods in unlock order; locked gods show their cost. Detail panel with weapon, passive, kit and lore. Difficulty modifier toggles. |
| Shrine of Embers | Menu | Unlock tree and powerups, with the Embers balance. |
| Quests | Menu | Twelve quests with progress and rewards. |
| Lore | Menu | Premise and every lore stone read. |
| Settings | Menu and pause | Master, music and effects volume; camera sensitivity; screen shake; invert camera Y; fullscreen. Saved in the save file. |
| HUD | Run | Health, XP bar, level, gold, stage clock or swarm timer, kills, minimap, loadout, boss bar, announcements, interaction prompt. |
| Level-up draft | Run | Three cards; Refresh, Skip, Banish with charges shown. |
| Shrine choice, lore page | Run | Paused pick-one screen; paused reading page. |
| Pause | Run | Resume, Settings, Give up the run, Leave to the menu. |
| Results | End of run | Reached, time, level, kills, bosses, chests, shrines, swarm, Embers earned, quests completed, balance, seed. Run again or go to the menu. |

## Controls

| Action | Keyboard and mouse | Gamepad |
|---|---|---|
| Move | WASD or arrows | Left stick |
| Look | Mouse | Right stick |
| Jump | Space | A / Cross |
| Slide (hold) | Left Shift or Left Ctrl | B / Circle or Left Trigger |
| Interact (hold) | E | X / Square |
| Pause, back | Esc | Start |
| Draft: pick | Click or 1, 2, 3 | D-pad or stick, then A |
| Draft: Refresh / Skip / Banish | R / Q / X | Y / LB / RB |

Every menu selects its first button on open, so the d-pad or stick and A work everywhere. Development builds add F1 level up, F2 heal, F3 kill all, F4 invincible, F5 skip 60 seconds, F6 wake the boss, F7 next stage.
